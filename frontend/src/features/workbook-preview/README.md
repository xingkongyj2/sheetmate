# 原始工作簿预览

`WorkbookPreview.vue` 是文件预览的统一入口，接收已上传文件的 `file: FileInfo`，或首页待发送附件的 `localFile: File`，关闭时发出 `close`。本地 XLSX/XLSM/CSV 优先在浏览器读取；完整样式无法解析或文件过大时，自动切换到鉴权的分页数据预览，所有预览均不创建会话或文件记录。

预览顶部仅保留文件信息和窗口操作，工作表通过底部原生 Sheet 标签切换。需要插入表名时，在聊天输入框中输入 `#` 筛选并选择工作表。

- XLSX / XLSM：原始文件经现有鉴权下载接口获取，在 Web Worker 中预检 ZIP 解压体积、单元格数量及合并面积，再由 ExcelJS 解析并映射为 Univer 快照。预览只在内存中的临时 ZIP 副本移除无法显示的绘图、批注、表对象及其关系，避开 ExcelJS 4.4 对合法对象关系的兼容性错误；单元格内容、合并、基础样式和公式缓存保持。原文件不会改写。
- CSV：在同一 Worker 中解码、识别分隔符，按文本值显示，保留前导零和原始坐标。
- 分页数据预览：旧 XLS、超过完整样式预览限制的工作簿，以及完整样式解析失败的文件使用同一分页界面，可切换工作表并翻页。已上传文件使用原有鉴权分页接口；尚未上传的附件按需提交到 `POST /api/files/preview-upload` 的后端临时目录，解析后删除，不创建会话或文件记录，并遵守系统上传限制。数据预览显示原始行列位置和单元格数据，不保留完整排版。
- `viewer.ts`：只读权限、中文界面、原生 Sheet 标签和缩放；隐藏编辑工具和菜单。
- `excel/`：与页面无关的 ExcelJS → Univer 转换模块。
- `worker-client.ts` / `parse.worker.ts`：隔离解析任务，关闭弹窗时终止，超时和异常可重试。

文件不会发送至外部服务，分页预览使用本应用已有后端临时解析接口。公式使用文件内缓存结果，复杂对象和缺少缓存的公式通过显示提示说明。整列数据验证、命名区域和条件格式不参与只读预览，避免解析器为这些区域展开数百万个空白对象。原件始终不被修改。

依赖采用同一固定版本的 Univer 开源核心，无 Pro 导入服务。`WorkbookPreview` 与 Univer 渲染器按需加载，不进入聊天首屏主包。

对话中的原始输入、期望结果和正式输出使用文件卡片，提供查看和下载，不重复展示解析后的数据表。回复中的说明性表格统一使用正文 Markdown 样式；临时查询和中间计算表仅在「执行明细」的数据区查看，不再作为独立卡片附加到回复下方。执行明细中的标准表格打开关联工作簿。数据展示规则位于 `composables/executionPresentation.ts`，文件关联和去重位于 `composables/filePresentation.ts`。
