# 思考模式与消耗页

实施日期：2026-11-10。

## 交付

- 首页和聊天页共享思考模式选择，按账号保存在当前浏览器。发送、刷新、重新进入会话均保留选择；开启和关闭都可记住。兼容旧首页草稿。
- 聊天页「执行明细」增加「消耗」页签，展示最新一轮消耗，以及当前对话全部轮次累计。包含输入、输出、模型调用次数；缓存和推理用量作为已有输入/输出的组成部分展示，不重复加总。
- 本轮采用深色数字卡片，累计采用浅色卡片，辅以输入/输出比例条。仅用「统计中」「含估算」「部分记录」等短标签表明状态；无记录显示 `—`。
- 实时报文、刷新后的历史消息、断线恢复共用累计用量快照。打开消耗页会刷新；执行或后台结算期间自动同步，结算完成后停止轮询。
- 标题生成和后台记忆的晚到用量回写来源轮次；无正文的澄清轮也通过请求 ID 对齐。重复快照不会累计两次，旧响应不会覆盖新用量。

## 统计口径

服务商返回 usage 时使用实报输入与输出。缺失 usage 时沿用既有预算统计中的保守估算并标记「含估算」，不将仍在请求中的预留额度计入消耗。推理 token 已在输出内，缓存 token 已在输入内。旧历史没有用量记录时不能补算成真实消耗；累计存在缺失轮次时标为「部分记录」。这里展示 token，不计算金额。
