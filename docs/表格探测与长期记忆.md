# 表格探测与长期记忆

表格事实与业务规则分别保存。当前文件有多少行、包含哪些列、哪些字段为空或重复，属于带版本的文件事实；计算关系、匹配方式、筛选口径，属于可复用的业务规则。

## 表格探测技能

内置 `table_info` 作为表格探测技能，负责完整字段、类型、样本、空值率、不同值数量、数值范围、合计和候选主键。`value_counts` 与 `column_stats` 保存带查询参数的分析结果。

上传时已经生成的画像直接复用。探测结果保存到 DuckDB 工作区的表目录中；同一表版本、相同探测参数直接读取，不再重新扫描。元数据改名不使内容记忆失效，同名重建、SQL 重建、删除后重建都会获得新内容版本。

每轮执行、普通聊天和思考模式都会获得当前可见表的完整结构和已有分析。字段清单、行列数和表头位置不通过模型摘要保存，也不受原来只显示前 14 列的限制。专员只得到自己可见表的结构记忆。

工作区中的记忆格式为版本化 JSON：

```json
{
  "schema_version": 1,
  "revision": "本次表内容版本",
  "profile": {
    "columns": [
      {
        "name": "金额",
        "dtype": "integer",
        "null_rate": 0,
        "unique": 3,
        "samples": [10, 20, 30],
        "min": 10,
        "max": 30,
        "sum": 60
      }
    ],
    "keys": {"candidates": [], "duplicated": []},
    "sample": {"columns": ["金额"], "rows": [[10], [20], [30]]}
  },
  "observations": [
    {
      "kind": "column_stats",
      "params": {"columns": ["金额"]},
      "result": {"columns": [], "dtypes": [], "rows": []}
    }
  ]
}
```

示例中的数字仅展示文件事实的存储方式。它们不构成流程中的固定值。

## 文件与会话之间的复用

原件通过文件 ID、SHA256 和工作表标识关联记忆。未变化时只检查文件状态，变化时重新计算摘要；同名、同样行列数但内容不同的文件不能共享旧探测结果。

分析在临时工作区中运行，结束或中断时，将探测事实合并回原工作区。合并前同时核对原表与分析副本的内容版本；已经改写的表不能把新事实回写给旧原件。

仍对应原件的画像和分析另存到 `FileRecord.profile.table_probe_memory`，其中记录文件 SHA256 和各工作表的便携记忆。相同原件在其他有访问权限的会话加载后可直接复用。新会话中尚未加载的文件也提供已验证结构记忆；实际计算仍使用真实加载后的工作区表。原件更新后旧记忆失效，修改过的文件副本不能污染原件记忆。

每张表保留最近 32 项按查询种类和参数去重的分布/统计，完整字段画像独立保留。普通 SQL 查询与业务分析文字不自动成为永久文件事实；已执行查询的结论、口径和证据由会话历史与摘要承接。

## 历史压缩

压缩前不再把每条消息裁到前 400 字。摘要通常约 1200 字，优先保留表与字段引用、版本、分析口径、结论证据、用户选择和未完成事项；重要事实较多时允许超出建议篇幅。

执行层沿用服务层已经整理的历史，不再提前丢弃尚未压缩的消息。需要较短历史的辅助判断仍保留压缩摘要，摘要不会随最近消息窗口滑出。

## 可复用业务规则

公式、SQL、脚本、流程学习、修改和修复使用同一默认规则：从本次输入、显式参数和对照表取得可变值，按真实表头、标签及数据边界定位；不能把当前样例里的日期、名单、分类、行数或合计改写为下次处理必须相同的条件。

用户明确指定的阈值、税率、固定期间、分类或输出列仍按要求保存。只有用户明确要求长期记住的业务口径才提取为长期规则，本次例外不自动覆盖旧规则。

动态透视默认使用运行时实际分类；保存流程时不会仅因人工样例只有若干列就裁掉下一批输入的新分类。用户明确指定固定输出列时保留该约定。既有流程中的常量不会在后台被推测改写，修订时按照本次明确要求处理。

## 实现入口

- `backend/sheetmate/agent/table_probe.py`：探测技能策略与上下文入口。
- `backend/sheetmate/engine/table_memory.py`：结构化存储、缓存读取、便携导入及版本检查。
- `backend/sheetmate/services/table_memory.py`：原件指纹、跨会话保存和恢复。
- `backend/sheetmate/services/analysis.py`：分析副本的有效探测回写。
- `backend/sheetmate/agent/prompts.py`：通用业务规则和结构化压缩约定。

回归测试覆盖重复调用不重新画像、重启复用、同形改值失效、分析失败后保留探测、修改副本不污染原件、跨会话恢复、宽表字段不裁剪、压缩后聊天可用，以及流程换数据后保留新增分类。
