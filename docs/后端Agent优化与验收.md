# 后端 Agent 优化与验收

实施日期：2026-11-10。对应此前的后端 Agent、长期记忆和上下文管理审计。代码与测试已在当前工作区实现；本次不调用付费模型服务，不以合成测试冒充真实业务正确率。

## 已实现

| 方向 | 实际行为 |
| --- | --- |
| 结果验证 | 编号与前导零精确比对；数值不再使用随金额放大的相对容差；时间戳保留时分秒与精度；额外/缺失行、重复键、关键业务列错误独立失败；空期望与非空结果失败 |
| 业务规则 | 缺失必需列失败，无法执行的规则返回 `not_evaluated`；恒定历史能拒绝异常；仅显式模型推断的 warning 候选可放宽，error 和自动检查不可自动降级 |
| 表格读取 | 记录物理/读取/数据行数、截断、表头置信度、公式缺缓存、Excel 错误坐标及有界公式表达式样例；受影响列拒绝统计；公式入口也校验输入，避免聚合/重命名丢掉质量风险；质量贯通文件画像、工作区、表格记忆与执行 |
| 工作表匹配 | 指定 sheet 缺失后，仅可靠且唯一的候选可继续；低分/并列候选明确失败；修复已复现的两层合并分组表头 |
| 跨表关联 | lookup 默认合并值一致的重复键，冲突拒绝；模糊匹配要求前两名得分差；JOIN 可声明关联基数并返回双方空键、重复键、覆盖率和结果行数 |
| 任务状态 | Conversation 持久化源消息引用、附件、授权、状态、未完成问题和证据 ID；路由、规划、执行读取同一来源要求；支持分页读取原文，严格限制在当前会话 |
| 历史上下文 | 按本地 token 估算触发压缩；摘要失败使用有界临时投影，不推进持久摘要游标；条件更新阻止旧摘要覆盖新摘要 |
| 每次模型输入 | 工具定义和数据投影一并计量；预算紧张时将有证据 ID 的旧工具结果投影为可回查摘要，保留近期结果、用户要求和调用/结果配对；无法满足边界时明确停止 |
| 表格事实 | 全量探测事实独立保存；模型只读取预算内投影；Top K 显示类别总数、遗漏类别数、真实覆盖行数和覆盖率；不把已返回类别数称为全部类别数 |
| 查询缓存 | 缓存确定性本地只读 SELECT，绑定查询与输入 revision；表更新自动失效；随机、时钟、采样、未知函数、窗口及可变嵌套单元格等绕过缓存；限制缓存大小 |
| 记忆来源 | 新增 source_message_id、source_turn_id、evidence_span、version；数据库条件更新与版本检查阻止并发旧写覆盖；同键并发创建只写一条；旧 SQLite 自动补列 |
| 记忆真实性 | 自动写入必须有当前用户原话依据，保存完整条件/否定句及跨行短段落；本次/临时/例外不升级为长期规则；人工规则不能被 AI 改写；回执展示实际保存值及 created/updated/unchanged/blocked/needs_evidence |
| 记忆作用域 | 仅未绑定流程的客户偏好/背景共享，已有流程规则继续隔离；相关经验有独立检索名额；人工约束超预算明确报告，不静默丢弃 |
| 工具菜单 | 普通任务使用稳定核心菜单，公式、工作簿、脚本、流程按需加载；参数仍完整校验；静态政策放在动态客户/表/记忆之前 |
| 意图识别 | 单次结构化路由同时返回保存流程授权和新任务/继续关系；旧服务缺字段时兼容回退；流程保存授权不由工具参数产生 |
| 并行分析 | 仅明确独立分析的任务启用；关联/匹配/对账保持完整跨表上下文；分支表权限、派生产物、证据和预算隔离，并为协调器预留操作次数 |
| SQL 范围 | 解析失败不执行；阻止动态 query/query_table、schema/catalog 及 CTE 逃逸绕过分支；不把不完整或公式质量异常的数据作为可靠全量计算输入 |
| 执行证据 | 每次工具结果有唯一 evidence ID、调用 ID、输入版本、参数哈希、结果行数和产物引用；完整原文持久保存，支持跨轮分页回查；跨会话不可读取 |
| 计划与核对 | 计划依赖显式化，无效/超长计划不静默删步骤；失败阻断依赖节点，允许独立节点继续；修正答案必须重新审计通过；失败不发布已知错误原答案；工具预算恰好耗尽不否定已核验完成的末步，未执行后续步骤仍保持未完成 |
| 模型预算 | 每个网络尝试、嵌套调用与并发调用共用预算，控制调用数、累计输入/总 token、耗时和单次输入；无 usage 明确估算，缓存/推理 token 单独记录，推理不重复加总 |
| 阶段策略 | 小型意图/标题/记忆/摘要默认关闭额外思考，复杂规划/修复/审计保留模型配置；调用方 max_tokens 不再被 thinking 模式丢弃 |
| 可观测性 | 保存阶段 usage、实报/缺失用量、缓存/推理 token、延迟及预算快照；标题与后台记忆的晚到用量回写到来源助手消息 |

## 配置

设置页的模型高级配置有“开启任务预算”总开关，按服务商保存，**默认关闭**。旧配置未保存开关时同样按关闭处理；关闭时只统计用量，不按累计 Token、模型调用次数、任务总时长或输入字符上限中断任务。上下文投影继续使用软目标压缩可回查的旧工具结果。开启后才执行下列预设阈值，0 可单独关闭某项限制：

| runtime_policy 字段 | 默认值 | 含义 |
| --- | ---: | --- |
| budget_enabled | false | 是否执行任务预算；关闭时保留阈值配置与用量记录 |
| max_model_calls | 120 | 一个任务累计网络请求次数，包含重试 |
| max_prompt_tokens | 300000 | 累计输入预算 |
| max_total_tokens | 500000 | 累计输入与输出预算，发请求前预留输出空间 |
| max_task_seconds | 600 | 当前任务发起及等待模型调用的时间边界 |
| max_input_chars | 240000 | 单次文本输入边界，包含工具定义 |
| auxiliary_thinking_enabled | false | 小型辅助阶段是否跟随模型深度思考 |

服务报告 usage 时以实际 usage 入账。缺失时采用公开记录的保守估算；图片输入也计入估算。预算只是运行保护，不是账单或服务商 tokenizer 的精确替代。

预算总开关的增量验证：新增后端 8 项回归与前端 3 项回归，覆盖旧配置默认关闭、超过旧累计预算后继续执行、五类门槛开启后生效、关闭时继续压缩可回查证据、保存开关并保留阈值。当前工作区后端全量 **183 项通过**、前端 **18 项通过**，类型检查与生产构建通过。已有后端进程需要重启以载入新增开关；之后按服务商保存的开关会在新任务读取。

## 边界与后续真实模型验收

- XLSX 仍有物理行读取边界；超过边界时明确标记并阻断完整统计/流程执行，本次没有实现所有格式的大文件流式重算。
- 没有内置 Excel/LibreOffice 公式计算服务；缺缓存和错误会显式暴露，不能当作零或空白完成统计。复杂多区域表头仍需原始区域证据和脚本检查。
- 默认数值验证使用半分以内的绝对误差，并保留业务硬约束；不是覆盖所有币种、数量、百分比和舍入阶段的通用精度契约。
- 自动新增 `history_insights` 暂停，直到写入接口具有可验证执行事件和适用范围。已有经验仍可检索；用户明确确认的长期规则可按用户来源保存。
- 永久/临时范围识别和中文召回使用保守文本策略，未引入向量数据库或额外的付费语义判断。
- 任务状态以原始用户消息和版本化证据为准，没有让模型自由重写并覆盖用户约束；新旧任务关系仍需路由正确识别。
- 本次没有更换模型，也没有进行真实付费模型 A/B 评测。上线后的准确率、P50/P95 延迟和每个正确完成任务的成本应在同一脱敏业务集、模型配置和重复运行条件下衡量。

真实评测建议至少包含：简单聚合、跨表对账、重复键/空键、退款、缺失映射、多层/多区域表头、同结构多月份 sheet、公式缓存、宽表、长会话修改口径、跨轮记忆及跨客户隔离。验收优先看错误放行率、关键金额和任务完整性，再评估 token 与耗时。
